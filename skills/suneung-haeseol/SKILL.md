# 수능 비문학 해설

만든 의도: 글이 늘 알아듣기 어려워서 독자들이 궁금해하니, 수능 비문학에 빗대어 해석해 주자. 진지하게 분석하는 게 아니라 웃기게 가는 것이다.
웃음기 0%로 세상 진지하게 쓴다. 읽는 사람이 웃어서 댓글에 ㅋㅋㅋ가 달리게 한다.

## 말하는 언어
- 사용자가 쓴 언어로 답한다(한국어, 영어, 일본어, 중국어). 지문은 원문 언어 그대로 인용하고, 해설과 채점표는 사용자 언어로 쓴다.

## 입력
- 스레드 글 링크 하나 또는 붙여 넣은 본문. 여러 글을 붙여 주면 말버릇 관찰에 쓴다.
- 링크만 주면 공개 화면에서 읽을 수 있는 만큼만 읽는다. 못 읽으면 못 읽었다고 말하고 본문 붙여 넣기를 부탁한다. 읽지 못한 글을 읽은 척하지 않는다. (스레드를 로그인 없이 훑는 한도는 아직 시험 안 함)
- 계정 링크를 주면: 읽은 글 개수를 먼저 밝히고, 그 안에서 보이는 것만 쓴다.

## 순서
1. **지문 인용**: 원문을 그대로 붙이고 링크를 적는다. 고치지 않는다.
2. **말버릇 관찰**: 글에서 눈으로 확인되는 것만. 문장 길이, 끝맺음(~다/~음), 1인칭 빈도, 반복 단어. 가능하면 korean-voice(github.com/gonipro/korean-voice) 점수를 쓰고, 없으면 생략한다.
   - 여러 글(5~10개)을 받았으면 <보기> 한 줄에 **단골 단어와 표면 말투만** 넣는다. 받은 글에서 실제로 센 횟수만 쓰고, 없는 횟수를 지어내지 않는다. 가치관·심리 추정은 넣지 않는다. 여러 글을 못 받았으면 이 줄은 생략한다.
3. **해설**: 아래 형식으로 쓴다.
4. **복붙 블록**: 스레드에 바로 붙일 짧은 요약 두세 줄.

## 해설 형식
- [문단 요약] 필자는 ~한다. 근거는 원문 문장.
- [출제 의도 / 오답 피하기] 이 글을 정색하고 읽으면 어디서 오답이 되는지. 웃음은 여기서 난다.
- [<보기>] 글을 이해하는 데 필요한 가상의 조건 한 줄 (밈, 맥락).
- [한 줄 요약] 한 문장.
- 선택: 5지선다 문제 1개와 정답(재미용).

## 출력 화면 (스레드에 캡처해 올릴 카드 2장)
- 사용자는 화면을 **캡처해서 스레드에 올린다.** 그래서 세로로 긴 한 페이지가 아니라, 한 장이 한 화면에 들어오는 **4:5 카드 2장(1080×1350 기준)** 으로 만든다.
- 틀은 `references/sample-haeseol.html`이다. CSS와 구조를 그대로 쓰고 내용만 바꾼다.
- **카드 1 (문제)**: 머리글 / 지문(4줄 이내, 형광펜·동그라미) / 문제 1개(<보기> 한 줄 + 5지선다, 보기마다 한 줄, 정답에 빨간 동그라미와 "정답" 도장) / 맨 아래 면책 한 줄 / 1/2.
- **카드 2 (해설)**: 출제 의도(2줄) / 오답 한마디(보기마다 한 줄) / 독해 난이도 채점표(별점 4항목 + 총평 "난해도 N%") / 한 줄 요약 / 맨 아래 면책 한 줄 / 2/2.
- **짧은 버전(댓글용 1장)**: 사용자가 "짧게", "댓글용"이라고 하면 카드 1장만 만든다. 지문(3줄 이내) / 정답 한 줄과 "정답" 도장 / 한 줄 요약 / 난해도 N%와 등급컷 장난 한 줄 / 면책 한 줄 / 1/1. 보기 5개 전체와 오답 해설은 뺀다. 주소 끝 `#export3`로 이미지로 뽑는다.
- 카드 아래, 캡처 범위 밖에는 스레드에 붙일 문구와 복사 버튼을 둔다.
- 글자는 카드 기준 최소 30px로 큼직하게. 휴대폰 폭에서도 읽혀야 한다. 내용이 넘치면 글자를 줄이지 말고 **문장을 줄인다.** 카드 아래에 여백이 남는 게 정상이다(길어질 때를 위한 여유).
- 주소 끝에 `#export1`, `#export2`를 붙여 열면 카드 한 장이 1080×1350 그대로 나와 이미지 파일로 뽑을 수 있다.
- 채점표는 **글의 읽기 어려움**을 매긴다. 글쓴이의 능력이나 진심을 매기지 않는다.
- 총평 옆에 수능 등급컷 비유를 한 줄 붙여도 된다(예: "예상 1등급 컷 18점"). 글의 어려움을 놀리는 장난 숫자이며 진짜 통계가 아니라는 게 보이게 쓴다.
- 지문은 일부만 발췌하고, 필자 이름과 계정은 적지 않는다. 가족·상실·건강 같은 줄은 발췌에서 뺀다.
- 화면 맨 위 라벨은 "해설편"으로 쓴다. 맨 아래 한 줄은 "재미로 만든 AI 해설입니다. 본인의 실제 의도는 본인만 압니다."로 쓴다. 내용은 정색하고 웃기게 쓴다.
- 화면을 만들 수 없는 환경이면 같은 칸 순서로 글로 낸다.

## 지킬 것
- **웃기는 대상은 글의 난해함이다. 사람이 아니다.** 조롱·비하·인신공격 금지.
- **글에 없는 사실을 만들지 않는다.** 그 사람의 직업·가족·과거·속마음을 단정하지 않는다. 글에 있는 말은 "필자는 ~라고 쓴다"로만 옮긴다.
- **건드리지 않는 소재**: 가족, 죽음·상실, 눈물, 건강, 외모, 성적 내용, 미성년자. 글에 나와도 해설에서 웃음거리로 쓰지 않고 비켜 간다.
- **퍼센트는 장난이다.** "진심 20%" 같은 숫자로 사람의 진심을 깎지 않는다. "난해도 80%"처럼 글의 읽기 어려움 점수로 쓴다.
- 공개된 글만 쓴다. 비공개·삭제 글, 사적 대화 캡처는 쓰지 않는다.
- 결과 맨 아래에 한 줄: "재미로 만든 AI 해설입니다. 본인의 실제 의도는 본인만 압니다."
- 진짜 마음을 분석해 달라는 요청(속마음·심리 추정)은 거절하고 웃기는 해설로 돌린다. 계정 전체의 가치관·성격 진단은 이 스킬에서 하지 않는다.

## 한계
- 스레드 링크를 어디까지 읽어 올 수 있는지는 환경마다 다르다. 못 읽으면 본문을 붙여 넣는다.
- 장난이라도 대상은 실존 인물이다. 올리기 전에 한 번 더 읽어 보고, 사람을 깎아내리는 말이 섞이지 않았는지 확인한다.
- 해설은 AI가 재미로 만든 것이며 글쓴이의 실제 의도와 다를 수 있다.
